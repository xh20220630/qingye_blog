## 可复用检查

```bash
pnpm lint
pnpm build
pnpm test:markdown
```

本次完整 lint 通过；两项交互修复后，对修改的组件与验证脚本再次执行定向 ESLint 并通过。最新构建包含 Astro 类型检查：61 个文件，0 错误、0 警告、0 提示。静态构建成功，`scripts/check-markdown.mjs` 共 16/16 组通过。

检查脚本接受可选构建目录参数：

```bash
node scripts/check-markdown.mjs /path/to/dist
```

静态脚本不会证明浏览器复制、图表水合、图片交互或外部播放器可用；这些结果由上述浏览器验证补充。
