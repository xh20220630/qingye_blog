# 博客功能

青野山房以可探索的修仙世界与文章阅读为中心。文章直接保存在 Markdown 文件中，站点设置直接编辑 JSON；没有管理员页面、在线编辑器、管理 API 或自动发布服务。

## 前台

| 领域 | 已实现 |
| --- | --- |
| 云海 | Three.js 体积云、分层流动与局部翻卷、三档风速平滑切换、透射、自阴影与晨昏光影 |
| 世界 | 六处仙山、Blender 楼阁与仙鹤、近观、相机漫游、键盘与触屏操作、暂停及画质调整 |
| 阅读 | 洞天内展开书卷、目录、代码复制、图片放大、阅读进度、续读、专注模式、打印与系列导航 |
| 检索 | 完整正文与代码索引、分类 / 标签 / 系列 / 年份组合筛选、排序、分页、命中高亮 |
| 袖囊 | 访客本机收藏与历史、读者账号同步、账号间记录隔离、主动导入访客袖囊、JSON 导出 |
| 账号 | 直接注册、登录、退出、称呼修改、密码修改，无初始化管理员步骤 |
| 留音 | 访客与读者留言、同一文章内回复、表单暂存、分页、审核后公开 |
| 订阅 | 全站与主题 RSS、JSON Feed |
| 搜索引擎 | Sitemap、robots、canonical、Open Graph、JSON-LD |

## 内容与运行

- 在 `src/content/blog/` 编辑 Markdown，在 `public/images/` 放置配图。
- 在 `src/site-settings.json` 修改站点信息、域名和友链。
- 构建并重启服务后更新文章。草稿与未来文章不会进入公开内容。
- SQLite 只供读者账号、评论、收藏和统计使用。既有私有数据保留，旧数据库中的文章副本不再控制网站内容。
- 留言可通过服务器本地命令审核；备份和密码恢复也使用本地工具，见 [运行说明](deployment.md)。
- 邮件群发、后台权限分级、在线写作、定时发布与媒体管理已移除。

阅读、分类和互动流程参考了 [WordPress 评论文档](https://wordpress.org/documentation/article/comments-in-wordpress/) 与 [Halo 文章文档](https://docs.halo.run/2.23/user-guide/posts)，按个人博客的实际使用范围实现。
